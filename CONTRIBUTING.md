# Contributing to Dashboard- (Linkieee)

Thanks for your interest in contributing! 🎉

## How to contribute

1. **Fork** this repository.
2. Create a new branch for your changes:
   - `git checkout -b feat/your-feature-name`
3. Make your changes with clear, focused commits.
4. Run checks locally before submitting:
   - Install dependencies: `pip install -r requirements.txt`
   - Verify notebook or scripts run without errors.
5. Open a Pull Request (PR) with:
   - A clear title
   - A short summary of what changed
   - Screenshots/logs if relevant

## Contribution ideas

- Improve training/inference reliability
- Add evaluation metrics and validation split
- Improve Bengali/English prompt quality
- Add tests and automation (CI)
- Documentation improvements

## Coding & style notes

- Keep changes small and reviewable.
- Add comments where logic is non-obvious.
- Avoid committing large datasets or secrets.
- Use descriptive names for files, functions, and variables.

## Reporting issues

If you find a bug or have a feature request, please open an issue and include:

- What you expected
- What happened
- Steps to reproduce
- Environment details (OS, Python version, GPU/CPU)

## Code of conduct

Please be respectful and constructive in all interactions.

Thanks for helping improve Linkieee 💙
